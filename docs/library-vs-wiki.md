# ห้องสมุดแตกต่างจาก Wiki อย่างไร

> งานค้นคว้าเปรียบเทียบ "ห้องสมุด" (Library) กับ "วิกิ" (Wiki) ในฐานะระบบจัดเก็บและ
> ให้เข้าถึงความรู้สองแบบ ที่มีเป้าหมายร่วมกันแต่ใช้กลไกคนละขั้ว

---

## 1. นิยามของแต่ละอย่าง

### 1.1 ห้องสมุด (Library) คืออะไร

ห้องสมุดคือ **ระบบจัดการสารสนเทศ** ที่ **คัดเลือก จัดหา จัดระเบียบ และให้บริการ**
ทรัพยากรความรู้ (หนังสือ วารสาร สื่อดิจิทัล ฯลฯ) ที่ "ผลิตจากภายนอก" โดยมีบรรณารักษ์
เป็นผู้ดูแล หัวใจของห้องสมุดคือการเป็น **ตัวกลางที่ผ่านการคัดกรอง (curated gateway)** —
ห้องสมุดไม่ได้ผลิตเนื้อหาเอง แต่ทำหน้าที่ "เลือกของดีที่สุดมาจัดวางให้ค้นเจอ"

> รายละเอียดกลไกการทำงานของห้องสมุด ดูได้ใน [how-library-works.md](how-library-works.md)

### 1.2 วิกิ (Wiki) คืออะไร

วิกิคือ **เว็บไซต์ที่ผู้ใช้ร่วมกันสร้างและแก้ไขเนื้อหาได้โดยตรงผ่านเบราว์เซอร์**
คำว่า *wiki* มาจากภาษาฮาวาย แปลว่า "เร็ว" ซอฟต์แวร์วิกิตัวแรก (WikiWikiWeb)
สร้างโดย Ward Cunningham ในปี 1995 และตัวอย่างที่ดังที่สุดคือ **Wikipedia** (เริ่มปี 2001)

แก่นของวิกิคือ **การสร้างเนื้อหาแบบร่วมมือ (collaborative authoring)** — ใครก็ตาม
(ตามสิทธิ์ที่ระบบเปิดให้) สามารถเพิ่ม แก้ไข หรือลบเนื้อหาได้ทันที โดยระบบจะเก็บ
**ประวัติการแก้ไข (version history)** ของทุกการเปลี่ยนแปลงไว้

> สรุปแก่นแกน: ห้องสมุด = "คลังที่ผ่านการคัดกรอง อ่านเป็นหลัก"
> ส่วนวิกิ = "ผืนผ้าใบที่ทุกคนร่วมเขียนได้ แก้ไขเป็นหลัก"

---

## 2. ความเหมือน: ทั้งคู่คือระบบจัดเก็บและเข้าถึงความรู้

ก่อนจะดูความต่าง ควรเห็นภาพว่าทั้งสองแก้ "โจทย์เดียวกัน" คือ
**ทำให้คนจำนวนมากเข้าถึงความรู้ได้** จึงมีจุดร่วมหลายอย่าง:

| จุดร่วม | ห้องสมุด | วิกิ |
|---------|----------|------|
| เป้าหมายหลัก | รวบรวมและกระจายความรู้ | รวบรวมและกระจายความรู้ |
| ต้องมีระบบค้นหา | OPAC / บัตรรายการ | ช่องค้นหา + ลิงก์ |
| ต้องจัดระเบียบเนื้อหา | ระบบจัดหมวดหมู่ (Dewey/LC) | หมวดหมู่ (Categories) + แท็ก |
| มี metadata อธิบายของ | ระเบียน MARC | กล่องข้อมูล (Infobox), หมวดหมู่ |
| ให้บริการคนหมู่มากพร้อมกัน | สมาชิกหลายคน | ผู้อ่านนับล้านพร้อมกัน |
| มีเป้าหมายเก็บรักษาความรู้ระยะยาว | สงวนรักษา (Preservation) | เก็บประวัติเวอร์ชัน + สำรองฐานข้อมูล |

ทั้งคู่จึงเป็น **"ดัชนี + คลัง"** ของความรู้เหมือนกัน ความต่างอยู่ที่
**ใครเป็นคนใส่ของเข้าไป และใครคุมคุณภาพ**

---

## 3. ความแตกต่างหลัก (เจาะลึกทีละประเด็น)

### 3.1 ผู้สร้างเนื้อหา (Who creates the content?)

นี่คือ **ความต่างที่เป็นต้นตอของความต่างอื่น ๆ ทั้งหมด**

- **ห้องสมุด:** เนื้อหามาจาก **มืออาชีพ** — ผู้แต่งที่มีคุณวุฒิ สำนักพิมพ์ที่มีกระบวนการ
  ตรวจสอบ บรรณาธิการ และ(สำหรับงานวิชาการ) ผู้ประเมินโดยผู้รู้เสมอกัน (peer reviewers)
  ห้องสมุดเป็นเพียง **ผู้คัดเลือก** ของที่ผ่านกระบวนการเหล่านี้มาแล้ว
- **วิกิ:** เนื้อหามาจาก **อาสาสมัครจำนวนมากแบบ crowdsourced** — ใครก็เขียนได้
  ไม่จำเป็นต้องมีคุณวุฒิหรือเปิดเผยตัวตน คุณภาพเกิดจาก "ปริมาณคนช่วยกันตรวจ"
  มากกว่า "อำนาจของผู้เขียนคนเดียว"

> เปรียบเทียบ: ห้องสมุด = ของที่ผ่าน **gatekeeper ก่อนเผยแพร่** (publish-then-nothing)
> วิกิ = เผยแพร่ก่อน แล้วค่อยช่วยกันแก้ทีหลัง (**publish-then-filter**)

### 3.2 การควบคุมคุณภาพและการตรวจสอบ (Quality control)

- **ห้องสมุด:** คุณภาพถูกคุมที่ **ต้นทางก่อนตีพิมพ์** — peer review, การตรวจของบรรณาธิการ,
  ชื่อเสียงของสำนักพิมพ์ และ **นโยบายการคัดเลือก (Collection Development Policy)**
  ของบรรณารักษ์ การควบคุมเป็นแบบ **รวมศูนย์ (centralized)** และเกิด "ก่อน" เนื้อหาถึงมือผู้อ่าน
- **วิกิ:** คุณภาพถูกคุมที่ **ปลายทางหลังเผยแพร่** ด้วย **การกำกับดูแลโดยชุมชน
  (community moderation)** — ผู้ใช้คนอื่นช่วยตรวจ ย้อนแก้การก่อกวน (revert vandalism)
  ถกเถียงในหน้าพูดคุย (Talk page) และอ้างนโยบาย (เช่น "ต้องอ้างอิงได้",
  "มุมมองเป็นกลาง") การควบคุมเป็นแบบ **กระจาย (distributed)** และต่อเนื่องตลอดเวลา

| มิติ | ห้องสมุด | วิกิ |
|------|----------|------|
| จุดควบคุม | ก่อนตีพิมพ์ (ต้นทาง) | หลังตีพิมพ์ (ปลายทาง) |
| ผู้ควบคุม | สำนักพิมพ์ + บรรณาธิการ + บรรณารักษ์ | ชุมชนผู้ใช้ + ผู้ดูแล (admins/bots) |
| กลไก | peer review, editorial process | revert, watchlist, talk page, นโยบาย |
| ลักษณะ | รวมศูนย์, เป็นจุด ๆ (เป็นครั้ง) | กระจาย, ต่อเนื่อง |

### 3.3 ความน่าเชื่อถือและการอ้างอิง (Authority & citation)

- **ห้องสมุด:** ทรัพยากรส่วนใหญ่ถือเป็น **แหล่งอ้างอิงที่เชื่อถือได้ (authoritative sources)**
  อ้างอิงในงานวิชาการได้โดยตรง เพราะมีผู้แต่งและสำนักพิมพ์รับผิดชอบชัดเจน
- **วิกิ:** มัก **ไม่ถือเป็นแหล่งอ้างอิงปฐมภูมิ** ในงานวิชาการ — แม้แต่ Wikipedia เองก็ระบุว่า
  ไม่ควรอ้างวิกิพีเดียโดยตรง แต่ควรใช้เป็น **จุดตั้งต้น** แล้วไปตามอ่าน "แหล่งอ้างอิงท้ายบทความ"
  (ซึ่งหลายแหล่งก็คือหนังสือ/บทความที่อยู่ในห้องสมุดนั่นเอง) ผู้ใช้วิกิจึง **ต้องระวัง**
  และตรวจสอบเชิงอรรถเอง

> น่าสังเกต: วิกิที่ดีมักทำหน้าที่เป็น "ดัชนีชี้ทาง" ไปยังแหล่งของห้องสมุด —
> ทั้งสองจึงเสริมกันมากกว่าจะแทนกัน

### 3.4 โครงสร้างการจัดระเบียบ (How content is organized)

- **ห้องสมุด:** ใช้ **ลำดับชั้นที่กำหนดไว้ล่วงหน้า (predefined hierarchy)** —
  ระบบจัดหมวดหมู่อย่าง Dewey (000–900) หรือ LC ที่หนังสือเรื่องใกล้กันอยู่ติดกันบนชั้น
  (locality) ของแต่ละเล่มมี "ที่อยู่เดียว" (เลขเรียกหนังสือ) เป็นโครงสร้างแบบ **ต้นไม้ (tree)**
- **วิกิ:** ใช้ **ลิงก์โยงกันอิสระ (hyperlinks) + หมวดหมู่ + แท็ก** — บทความหนึ่งโยงไปหลายบทความ
  ได้ไม่จำกัด และอยู่ในหลายหมวดพร้อมกันได้ เป็นโครงสร้างแบบ **กราฟ (graph)** ที่ผู้ใช้
  ท่องไปตามลิงก์ (browsing by association) ไม่ใช่ตามตำแหน่งกายภาพ

| มิติ | ห้องสมุด | วิกิ |
|------|----------|------|
| โครงสร้าง | ลำดับชั้น (tree) | โครงข่ายลิงก์ (graph) |
| ของหนึ่งชิ้นอยู่กี่ที่ | ที่เดียว (เลขเรียกเดียว) | หลายหมวด/หลายลิงก์ได้ |
| วิธีนำทาง | ตามเลขหมู่/ชั้น | ตามลิงก์ที่โยงถึงกัน |
| คำเปรียบเทียบ | แฟ้มเอกสารในตู้ | ใยแมงมุมของหน้าเว็บ |

### 3.5 ความคงที่ของเนื้อหา (Static vs Mutable)

- **ห้องสมุด:** หนังสือที่พิมพ์แล้วคือ **ฉบับที่ตายตัว (static / immutable)** — เนื้อหาในเล่ม
  เปลี่ยนไม่ได้ การแก้ไขทำได้ก็ต่อเมื่อออก "ฉบับพิมพ์ใหม่ (new edition)" ซึ่งเป็น
  คนละรายการ ทำให้ **อ้างอิงเลขหน้าได้แม่นยำและคงที่ตลอดกาล**
- **วิกิ:** เนื้อหา **แก้ไขได้ตลอดเวลา (mutable)** บทความวันนี้กับเมื่อปีก่อนอาจต่างกันมาก
  แต่ระบบเก็บ **ประวัติการแก้ไขทุกครั้ง (edit history)** ไว้ ทำให้ย้อนดูเวอร์ชันใด ๆ
  เปรียบเทียบความต่าง (diff) และย้อนกลับ (revert) ได้

> นี่คือคู่ตรงข้ามคลาสสิก: **immutable (เปลี่ยนไม่ได้) vs mutable (เปลี่ยนได้)**
> ห้องสมุดได้ "ความเสถียรและอ้างอิงได้" ส่วนวิกิได้ "ความสด ทันสมัย และแก้ผิดได้เร็ว"

### 3.6 รูปแบบทรัพยากร (Physical vs Digital)

- **ห้องสมุด:** มีทั้ง **กายภาพ (หนังสือ วารสาร แผนที่ สื่อโสตทัศน์)** และ **ดิจิทัล
  (e-book, ฐานข้อมูล)** ทรัพยากรกายภาพมี "เล่มจริงจำนวนจำกัด" จึงต้องมีระบบยืม-คืน
- **วิกิ:** เป็น **ดิจิทัลล้วน (born-digital)** ไม่มีตัวตนทางกายภาพ ทำสำเนาได้ไม่จำกัดต้นทุน
  (zero marginal cost) จึงไม่ต้อง "ยืม-คืน" และเข้าถึงพร้อมกันได้ไม่จำกัดจำนวนคน

### 3.7 การเข้าถึงและลิขสิทธิ์ (Access & licensing)

- **ห้องสมุด:** ทรัพยากรส่วนใหญ่ **มีลิขสิทธิ์ (copyrighted)** ห้องสมุด "ซื้อสิทธิ์การใช้/
  บอกรับ" มาเพื่อให้สมาชิกใช้ภายใต้เงื่อนไข (เช่น ยืมได้ครั้งละกี่เล่ม กี่วัน,
  e-book จำกัดจำนวนผู้ใช้พร้อมกัน) มักต้องเป็น **สมาชิก** จึงเข้าถึงเต็มที่
- **วิกิ:** มักใช้ **สัญญาอนุญาตแบบเปิด** เช่น Wikipedia ใช้ **Creative Commons (CC BY-SA)**
  เปิดให้อ่าน คัดลอก และนำไปต่อยอดได้เสรี (ตามเงื่อนไขแสดงที่มาและใช้สัญญาเดียวกัน)
  เข้าถึงได้ฟรีโดยไม่ต้องสมัครสมาชิก

### 3.8 การค้นหา (Discovery & search)

- **ห้องสมุด:** ค้นผ่าน **แคตตาล็อก (OPAC)** ซึ่งค้นจาก **metadata** เป็นหลัก —
  ชื่อเรื่อง ผู้แต่ง หัวเรื่องมาตรฐาน (controlled vocabulary) เลข ISBN ฯลฯ
  โดยทั่วไป **ไม่ได้ค้นทุกคำในเนื้อหนังสือ** (ยกเว้นทรัพยากรดิจิทัลที่ทำดัชนีฉบับเต็ม)
- **วิกิ:** ค้นแบบ **full-text search** ค้นได้ทุกคำในทุกบทความทันที บวกกับการ
  **ท่องไปตามไฮเปอร์ลิงก์** ที่โยงบทความถึงกัน ทำให้ค้นพบเนื้อหาที่เกี่ยวข้องได้ลื่นไหล

| มิติ | ห้องสมุด (OPAC) | วิกิ |
|------|----------------|------|
| ค้นจากอะไร | metadata + หัวเรื่องมาตรฐาน | ข้อความฉบับเต็ม (full text) |
| คำค้น | ศัพท์ควบคุม (มาตรฐาน) | คำธรรมดาอะไรก็ได้ |
| การนำทางต่อ | ตามเลขหมู่/หัวเรื่องที่ใกล้กัน | ตามลิงก์ในบทความ |
| ขอบเขต | "มีของชิ้นนี้ไหม อยู่ไหน ว่างไหม" | "เนื้อหาว่าอะไร" ทันที |

## 4. ตารางเปรียบเทียบสรุป (Side-by-side)

| ประเด็น | 📚 ห้องสมุด (Library) | 🌐 วิกิ (Wiki) |
|---------|----------------------|----------------|
| ผู้สร้างเนื้อหา | มืออาชีพ / สำนักพิมพ์ | ใครก็แก้ได้ / crowdsourced |
| คุมคุณภาพเมื่อไร | ก่อนตีพิมพ์ (peer review, บรรณาธิการ) | หลังเผยแพร่ (community moderation) |
| ลักษณะการคุม | รวมศูนย์ | กระจาย |
| ความน่าเชื่อถือ | authoritative อ้างอิงได้ตรง | ต้องระวัง ใช้เป็นจุดตั้งต้น |
| การจัดระเบียบ | classification / Dewey, LC (tree) | hyperlink + category + tag (graph) |
| ความคงที่ | static / immutable (ฉบับพิมพ์) | mutable แก้ได้ตลอด + edit history |
| รูปแบบ | กายภาพ + ดิจิทัล | ดิจิทัลล้วน |
| ตัวเล่ม/สำเนา | จำกัด ต้องยืม-คืน | ไม่จำกัด เข้าพร้อมกันได้ |
| ลิขสิทธิ์ | มีลิขสิทธิ์ ซื้อ/บอกรับ มักต้องเป็นสมาชิก | เปิด (เช่น CC BY-SA) เข้าถึงฟรี |
| การค้นหา | OPAC ค้นจาก metadata | full-text + ลิงก์ |
| ประวัติการเปลี่ยนแปลง | ผ่าน "edition" ใหม่ | บันทึกทุกการแก้ (diff/revert) |
| ความเร็วในการอัปเดต | ช้า (รอพิมพ์ใหม่) | เร็วมาก (ทันที) |

## 5. การเทียบเคียงกับวิทยาการคอมพิวเตอร์

เช่นเดียวกับเอกสารอื่นในชุดนี้ ความต่างระหว่างห้องสมุดกับวิกิสะท้อนแนวคิดคลาสสิก
ในวิทยาการคอมพิวเตอร์ได้อย่างน่าสนใจ:

| ห้องสมุด vs วิกิ | แนวคิดในคอมพิวเตอร์ |
|------------------|---------------------|
| ห้องสมุด = อ่านเป็นหลัก คัดมาแล้ว | **Read-optimized / curated store** (เช่น data warehouse, CDN) |
| วิกิ = แก้ไขร่วมกันตลอดเวลา | **Collaborative editable store** + **version control** (Git), **CRDT** |
| หนังสือฉบับพิมพ์ (เปลี่ยนไม่ได้) | **Immutable data** (write-once, append-only log) |
| บทความวิกิ (แก้ได้) + edit history | **Mutable state** + **commit history / diff** |
| ฉบับพิมพ์ใหม่ = รายการใหม่ | **Versioning / new release tag** |
| คุมคุณภาพก่อนตีพิมพ์ (บรรณาธิการ) | **Validation ที่ write time** (schema/constraint ก่อนเขียน) |
| คุมคุณภาพหลังเผยแพร่ (ชุมชนแก้) | **Eventual consistency** (ค่อย ๆ ลู่เข้าหาความถูกต้อง) |
| สำนักพิมพ์/บรรณารักษ์เป็นผู้มีอำนาจ | **Centralized authority** (single source of truth) |
| ใครก็แก้วิกิได้ | **Distributed / decentralized authority** (peer-to-peer) |
| classification แบบ Dewey/LC | **Hierarchical index / B-Tree** (ลำดับชั้น) |
| ลิงก์โยงกันในวิกิ | **Graph / adjacency list** (โหนดเชื่อมกันด้วยเส้น) |
| ค้นจาก metadata (OPAC) | **Index lookup ตาม key** |
| full-text search ในวิกิ | **Inverted index** (ค้นทุกคำในเนื้อหา) |
| revert การก่อกวน | **Rollback / undo จาก version history** |

> สรุปแก่นความต่างเชิงระบบ: ห้องสมุดคือระบบที่เน้น **immutable + centralized authority +
> read-optimized** (เสถียร เชื่อถือได้ อ้างอิงได้) ส่วนวิกิคือระบบที่เน้น
> **mutable + distributed authority + write-friendly** (สด ยืดหยุ่น แก้ผิดเร็ว
> แต่ต้องลู่เข้าหาความถูกต้องด้วยคนหมู่มาก)

## 6. บทสรุป: เมื่อไรควรใช้แบบไหน และทั้งสองเสริมกันอย่างไร

ทั้งห้องสมุดและวิกิแก้โจทย์ใหญ่อันเดียวกัน — **เก็บความรู้และทำให้คนเข้าถึงได้** —
แต่ด้วยปรัชญาคนละขั้ว จึงเหมาะกับสถานการณ์ต่างกัน:

**ควรพึ่งห้องสมุด (หรือแหล่งที่ผ่านการคัดกรอง) เมื่อ:**
- ต้องการแหล่งอ้างอิงที่เชื่อถือได้สำหรับงานวิชาการ/วิจัย
- ต้องการเนื้อหาเชิงลึก ครบถ้วน ผ่านการตรวจสอบ และอ้างเลขหน้าได้คงที่
- ต้องการความเสถียรของข้อมูลที่ไม่เปลี่ยนใต้เท้าเรา

**ควรพึ่งวิกิ เมื่อ:**
- ต้องการภาพรวมอย่างรวดเร็ว เพื่อ "ตั้งต้น" ทำความเข้าใจหัวข้อใหม่
- ต้องการข้อมูลที่สดและทันเหตุการณ์ปัจจุบัน
- ต้องการตามลิงก์สำรวจหัวข้อที่เกี่ยวข้องอย่างอิสระ

**ทั้งสองเสริมกัน (complementary) อย่างไร:**
ในทางปฏิบัติ วิธีที่ดีที่สุดคือ **ใช้วิกิเป็นจุดเริ่มต้น แล้วใช้ห้องสมุดเป็นจุดยืนยัน** —
อ่านบทความวิกิเพื่อจับภาพรวมและคำสำคัญ จากนั้นตามรายการอ้างอิงท้ายบทความ
(ซึ่งจำนวนมากคือหนังสือและบทความวิชาการ) ไปหาตัวจริงในห้องสมุดเพื่อความน่าเชื่อถือ
วิกิจึงมักทำหน้าที่เป็น **"ดัชนีชี้ทางสาธารณะ"** ไปยังคลังความรู้ที่ห้องสมุดดูแลอยู่

> กล่าวอีกนัยหนึ่ง: ห้องสมุดให้ **"ความลึกและความน่าเชื่อถือ"**
> วิกิให้ **"ความกว้าง ความเร็ว และการเชื่อมโยง"** —
> ระบบความรู้ที่สมบูรณ์ที่สุดของยุคนี้คือการใช้ทั้งสองอย่างร่วมกัน
