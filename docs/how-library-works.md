# ห้องสมุดทำงานอย่างไร

> งานค้นคว้าว่าด้วยกลไกเบื้องหลังการทำงานของห้องสมุด ตั้งแต่หนังสือเข้ามาจนถึงมือผู้อ่าน

---

## 1. ห้องสมุดคืออะไรในเชิงระบบ

ถ้ามองให้ลึก ห้องสมุดไม่ใช่แค่ "อาคารที่มีหนังสือเยอะ ๆ" แต่เป็น **ระบบจัดการสารสนเทศ
(Information Management System)** ที่ต้องแก้โจทย์เดียวกับที่ระบบฐานข้อมูลคอมพิวเตอร์แก้ คือ:

> **ทำอย่างไรให้คนจำนวนมาก ค้นหาและหยิบใช้ "ของชิ้นเดียว" จาก "ของนับแสนชิ้น" ได้อย่างรวดเร็ว
> ถูกต้อง และไม่ตีกัน?**

ห้องสมุดตอบโจทย์นี้ด้วย 4 หน้าที่หลักที่ทำงานต่อเนื่องเป็นวงจร:

| หน้าที่ | ภาษาอังกฤษ | ทำอะไร |
|---------|-----------|--------|
| การจัดหา | Acquisition | คัดเลือกและซื้อ/รับบริจาคทรัพยากรเข้าห้องสมุด |
| การวิเคราะห์หมวดหมู่ | Cataloging & Classification | ลงรายการและจัดหมวดหมู่ให้ค้นหาเจอ |
| การบริการยืม-คืน | Circulation | ควบคุมการหมุนเวียนทรัพยากรออก-เข้า |
| การบริการอ้างอิง | Reference Service | ช่วยผู้ใช้ค้นหาและเข้าถึงข้อมูล |

---

## 2. วงจรชีวิตของหนังสือหนึ่งเล่ม (Life Cycle)

วิธีที่ดีที่สุดในการเข้าใจห้องสมุด คือเดินตามหนังสือหนึ่งเล่มตั้งแต่ต้นจนจบ:

```
[1] จัดหา ──► [2] ลงทะเบียน ──► [3] วิเคราะห์หมวดหมู่ ──► [4] เตรียมตัวเล่ม
   (Acquire)     (Accession)      (Catalog/Classify)        (Processing)
                                                                  │
                                                                  ▼
[8] จำหน่ายออก ◄── [7] สงวนรักษา ◄── [6] ยืม-คืน ◄────── [5] ขึ้นชั้น
   (Weeding)        (Preservation)    (Circulation)        (Shelving)
```

### [1] การจัดหา (Acquisition)
บรรณารักษ์คัดเลือกหนังสือตามนโยบายการพัฒนาทรัพยากร (Collection Development Policy)
โดยดูความต้องการของผู้ใช้ งบประมาณ และความสมดุลของเนื้อหา จากนั้นสั่งซื้อหรือรับบริจาค

### [2] การลงทะเบียน (Accessioning)
หนังสือทุกเล่มได้ **หมายเลขทะเบียน (Accession Number)** ที่ไม่ซ้ำกัน เปรียบเหมือน
Primary Key ในฐานข้อมูล ใช้ระบุ "ตัวเล่มจริง" (physical copy) แต่ละเล่ม

### [3] การวิเคราะห์หมวดหมู่ (Cataloging & Classification) — หัวใจของห้องสมุด
ขั้นตอนนี้คือสิ่งที่ทำให้ห้องสมุด "ทำงานได้" แบ่งเป็น 2 ส่วน:

- **Cataloging (การลงรายการ):** สร้าง "ระเบียน" (record) บันทึกข้อมูลของหนังสือ —
  ชื่อเรื่อง ผู้แต่ง สำนักพิมพ์ ปี ISBN หัวเรื่อง ฯลฯ — นี่คือ **metadata**
- **Classification (การจัดหมวดหมู่):** ให้ **เลขเรียกหนังสือ (Call Number)**
  ซึ่งระบุ "ตำแหน่งบนชั้น" ของหนังสือ

### [4]-[5] เตรียมตัวเล่มและขึ้นชั้น (Processing & Shelving)
ติดบาร์โค้ด/แท็ก RFID ติดสันเลขเรียกหนังสือ ห่อปก แล้วนำขึ้นชั้นตามเลขเรียกหนังสือ

### [6] การยืม-คืน (Circulation)
ระบบควบคุมว่าใครยืมเล่มไหน กำหนดส่งวันใด คิดค่าปรับ จองคิว ฯลฯ

### [7] การสงวนรักษา (Preservation)
ซ่อมแซม เข้าเล่มใหม่ ควบคุมอุณหภูมิ/ความชื้น ป้องกันแมลงและเชื้อรา

### [8] การจำหน่ายออก (Weeding / Deselection)
คัดหนังสือที่เก่า ชำรุด ล้าสมัย หรือไม่มีคนยืม ออกจากระบบเพื่อคืนพื้นที่

## 3. ระบบจัดหมวดหมู่: หัวใจของการค้นหา

ปัญหาใหญ่ที่สุดของห้องสมุดคือ **"จะหาหนังสือ 1 เล่มจากแสนเล่มเจอได้อย่างไร?"**
คำตอบคือ **ระบบจัดหมวดหมู่ (Classification System)** ซึ่งเปลี่ยน "เนื้อหา" ของหนังสือ
ให้เป็น "ตำแหน่ง" บนชั้นที่คาดเดาได้

### 3.1 ระบบทศนิยมดิวอี้ (Dewey Decimal Classification — DDC)
นิยมในห้องสมุดประชาชนและโรงเรียน แบ่งความรู้ทั้งหมดออกเป็น 10 หมวดใหญ่ (000–900):

| เลข | หมวด |
|-----|------|
| 000 | วิทยาการคอมพิวเตอร์ สารสนเทศ ความรู้ทั่วไป |
| 100 | ปรัชญาและจิตวิทยา |
| 200 | ศาสนา |
| 300 | สังคมศาสตร์ |
| 400 | ภาษา |
| 500 | วิทยาศาสตร์ |
| 600 | เทคโนโลยี |
| 700 | ศิลปะและนันทนาการ |
| 800 | วรรณกรรม |
| 900 | ประวัติศาสตร์และภูมิศาสตร์ |

แต่ละหมวดแบ่งย่อยได้ละเอียดด้วยทศนิยม เช่น `005.13` = ภาษาโปรแกรม
ทำให้หนังสือเนื้อหาใกล้กันอยู่ใกล้กันบนชั้นเสมอ (**locality** — ของที่เกี่ยวข้องกันอยู่ติดกัน)

### 3.2 ระบบหอสมุดรัฐสภาอเมริกัน (Library of Congress — LCC)
นิยมในห้องสมุดมหาวิทยาลัย/วิจัยที่มีหนังสือจำนวนมาก ใช้ตัวอักษร A–Z นำหน้า
ทำให้แบ่งหมวดได้กว้างกว่า (21 หมวดหลัก) รองรับคอลเลกชันขนาดใหญ่ได้ดีกว่า DDC

### 3.3 เลขเรียกหนังสือ (Call Number)
เลขเรียกหนังสือคือ "ที่อยู่" ของหนังสือ ประกอบด้วย:

```
   005.133        ◄── เลขหมู่ (Classification number) = อยู่หมวดไหน
   P768p          ◄── เลขผู้แต่ง (Cutter number) = เรียงตามผู้แต่ง
   2024           ◄── ปีพิมพ์
```

หนังสือถูกเรียงบนชั้นตามเลขนี้จากซ้ายไปขวา บนลงล่าง ทำให้:
- **ค้นหาได้** (รู้เลข = เดินไปหยิบได้เลย)
- **เรียงลำดับได้** (sorted order)
- **แทรกเล่มใหม่ได้** โดยไม่ต้องจัดชั้นใหม่ทั้งหมด

## 4. ระบบเทคโนโลยีเบื้องหลัง

### 4.1 ระบบห้องสมุดอัตโนมัติ (ILS — Integrated Library System)
ซอฟต์แวร์แกนกลางที่รวมทุกงานไว้ด้วยกัน (เช่น Koha, Alma, Sierra) มีโมดูล:
จัดหา, ลงรายการ, ยืม-คืน, OPAC, การจัดการวารสาร และรายงาน

### 4.2 OPAC (Online Public Access Catalog)
"เครื่องมือค้นหา" ของห้องสมุด — ฐานข้อมูลที่ผู้ใช้ค้นได้เองว่าหนังสือเล่มที่ต้องการ
อยู่หมวดไหน เลขเรียกอะไร และตอนนี้ "ว่าง" หรือ "ถูกยืมไปแล้ว"

### 4.3 มาตรฐาน MARC และ ISBD
**MARC (Machine-Readable Cataloging)** คือรูปแบบมาตรฐานในการเก็บระเบียนหนังสือ
ให้คอมพิวเตอร์อ่านได้ ทำให้ห้องสมุดทั่วโลก **แลกเปลี่ยนข้อมูลกันได้** —
ลงรายการหนังสือเล่มหนึ่งที่เดียว แล้วห้องสมุดอื่นดึงไปใช้ต่อได้ (copy cataloging)

### 4.4 บาร์โค้ดและ RFID
- **บาร์โค้ด:** ระบุตัวเล่มแต่ละเล่ม สแกนตอนยืม-คืน
- **RFID:** แท็กคลื่นวิทยุ อ่านทีละหลายเล่มพร้อมกัน ใช้ยืมด้วยตัวเอง (self-checkout),
  ตรวจนับชั้น และเป็นระบบกันขโมยในตัว

## 5. การเทียบเคียงกับวิทยาการคอมพิวเตอร์

ที่น่าสนใจคือ ปัญหาของห้องสมุดคือ **ต้นแบบของโครงสร้างข้อมูลและอัลกอริทึม** ในคอมพิวเตอร์:

| แนวคิดในห้องสมุด | แนวคิดในคอมพิวเตอร์ |
|------------------|---------------------|
| บัตรรายการ / OPAC | **Index** (ดัชนีค้นหา) |
| เลขเรียกหนังสือเรียงบนชั้น | **Sorted array / B-Tree** |
| ระบบจัดหมวดหมู่ | **Hashing / Key mapping** |
| หมายเลขทะเบียน (Accession No.) | **Primary Key** |
| ระเบียน MARC | **Record / Schema** |
| หนังสือถูกยืม รอคืน | **Lock / Mutex** (กันใช้ซ้ำซ้อน) |
| ชั้นหนังสือสำรอง (Reserve) | **Cache** (ของที่ใช้บ่อยวางใกล้มือ) |
| ยืมระหว่างห้องสมุด (ILL) | **Distributed system / Sharding** |
| สำเนาหลายเล่ม | **Replication** |
| คำว่า "Library" ในการเขียนโปรแกรม | มาจากแนวคิดนี้โดยตรง |

แม้แต่คำว่า **"library"** ในภาษาโปรแกรมมิ่ง (ชุดโค้ดสำเร็จรูปที่เรียกใช้ซ้ำได้)
ก็ยืมแนวคิดมาจากห้องสมุดจริง คือ "คลังของที่จัดระเบียบไว้ให้หยิบมาใช้ซ้ำได้"

---

## 6. สรุป

ห้องสมุดทำงานได้เพราะมันคือ **ระบบ** ไม่ใช่แค่กองหนังสือ:

1. **จัดหา** ของเข้ามาอย่างมีนโยบาย
2. **จัดระเบียบ** ด้วย metadata และระบบจัดหมวดหมู่ ให้ทุกเล่มมี "ที่อยู่" ที่ค้นหาได้
3. **ค้นหา** ผ่านดัชนี (OPAC) ที่แยกออกจากตัวของจริง
4. **หมุนเวียน** ทรัพยากรชิ้นเดียวให้คนจำนวนมากใช้ร่วมกันโดยไม่ตีกัน
5. **รักษา** ของให้อยู่นาน และ **คัดออก** ของที่หมดประโยชน์
