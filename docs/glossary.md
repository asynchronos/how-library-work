# อภิธานศัพท์ห้องสมุด (Glossary)

รวมคำศัพท์สำคัญที่ใช้ในงานค้นคว้านี้ เรียงตามหมวดการทำงาน

## งานเทคนิคและการจัดหมวดหมู่

| คำศัพท์ | ความหมาย |
|---------|----------|
| **Cataloging** | การลงรายการ — บันทึก metadata ของทรัพยากร (ชื่อเรื่อง ผู้แต่ง ฯลฯ) |
| **Classification** | การจัดหมวดหมู่ — กำหนดเลขหมู่ตามเนื้อหา |
| **DDC (Dewey Decimal)** | ระบบทศนิยมดิวอี้ แบ่งความรู้เป็น 10 หมวด (000–900) นิยมในห้องสมุดประชาชน |
| **LCC (Library of Congress)** | ระบบหอสมุดรัฐสภาอเมริกัน ใช้ตัวอักษร A–Z นิยมในห้องสมุดมหาวิทยาลัย |
| **Call Number** | เลขเรียกหนังสือ — "ที่อยู่" ของหนังสือบนชั้น |
| **Cutter Number** | เลขผู้แต่ง — ส่วนของเลขเรียกที่ใช้เรียงตามชื่อผู้แต่ง |
| **Accession Number** | หมายเลขทะเบียน — รหัสไม่ซ้ำของตัวเล่มจริงแต่ละเล่ม |
| **MARC** | Machine-Readable Cataloging — มาตรฐานรูปแบบระเบียนที่เครื่องอ่านได้ |
| **RDA / AACR2** | กฎเกณฑ์การลงรายการ (RDA เป็นมาตรฐานใหม่กว่า) |
| **ISBD** | มาตรฐานสากลการลงรายการบรรณานุกรม |
| **Subject Headings (LCSH)** | หัวเรื่องมาตรฐาน — คำค้นที่ควบคุมให้เป็นแบบเดียวกัน |
| **Controlled Vocabulary** | ศัพท์ควบคุม — ชุดคำมาตรฐานเพื่อให้ค้นเจอแม้ใช้คำต่างกัน |
| **Metadata** | ข้อมูลที่อธิบายตัวทรัพยากร (ข้อมูลเกี่ยวกับข้อมูล) |

## ระบบและเทคโนโลยี

| คำศัพท์ | ความหมาย |
|---------|----------|
| **ILS** | Integrated Library System — ซอฟต์แวร์แกนกลางของห้องสมุด (Koha, Alma ฯลฯ) |
| **OPAC** | Online Public Access Catalog — ระบบสืบค้นออนไลน์สำหรับผู้ใช้ |
| **Card Catalog** | บัตรรายการ — ระบบสืบค้นแบบบัตรกระดาษในอดีต |
| **RFID** | แท็กคลื่นวิทยุ ใช้ยืม-คืน ตรวจนับ และกันขโมย |
| **Barcode** | บาร์โค้ดระบุตัวเล่ม สแกนตอนยืม-คืน |
| **Union Catalog** | สหบรรณานุกรม — ฐานข้อมูลรวมหลายห้องสมุด เช่น WorldCat |

## บริการและการหมุนเวียน

| คำศัพท์ | ความหมาย |
|---------|----------|
| **Acquisition** | งานจัดหา — คัดเลือกและจัดซื้อทรัพยากร |
| **Circulation** | งานบริการยืม-คืน |
| **Due Date** | วันกำหนดส่งคืน |
| **Hold / Reservation** | การจองคิวทรัพยากรที่ถูกยืมอยู่ |
| **Fine** | ค่าปรับเมื่อคืนเกินกำหนด |
| **Reserve** | ชั้นหนังสือสำรอง — ทรัพยากรที่ยืมได้สั้น/ใช้ในห้องสมุด |
| **Reference Service** | บริการตอบคำถามและช่วยค้นคว้า |
| **ILL (Interlibrary Loan)** | บริการยืมระหว่างห้องสมุด |
| **Information Literacy** | การรู้สารสนเทศ — ทักษะค้นและประเมินข้อมูล |

## การจัดการคอลเลกชันและสงวนรักษา

| คำศัพท์ | ความหมาย |
|---------|----------|
| **Collection Development** | การพัฒนาทรัพยากร — นโยบายว่าจะเก็บอะไรเข้าห้องสมุด |
| **Weeding (Deselection)** | การคัดทรัพยากรออกจากระบบ |
| **MUSTIE** | เกณฑ์คัดออก: Misleading, Ugly, Superseded, Trivial, Irrelevant, Elsewhere |
| **Preservation** | การสงวนรักษาทรัพยากรให้อยู่ได้นาน |
| **Conservation** | การอนุรักษ์/ซ่อมแซมทรัพยากรเฉพาะชิ้น |
| **Digitization** | การแปลงทรัพยากรกายภาพเป็นดิจิทัล |
| **Consortium** | ภาคีห้องสมุด — รวมกลุ่มเพื่อแชร์ทรัพยากร/ต่อรองราคา |

## รหัสมาตรฐาน

| คำศัพท์ | ความหมาย |
|---------|----------|
| **ISBN** | รหัสมาตรฐานสากลประจำหนังสือ |
| **ISSN** | รหัสมาตรฐานสากลประจำวารสาร |
